# dsh-notice-webhook · 项目文档

> **TL;DR**：本包是 DSH 的通知插件（Host 半 + 客户端半），把「会话完成 / 等待授权 / 等待回答 / 目标终态」
> 按**目标集合**推送到 6 种渠道，并提供一个设置页与一个可嵌入选择器。
> 完成通知带**完成闸门**：本轮把活交出去——不管是后台 job 还是还没跑完的子代理——都不报「完成」。
> 并且**自动跑不吵人**：系统自己唤醒的轮次（goal 自动轮 / 看板 Dive 自动续跑 / 插件注入）不推完成通知，
> 只有真人参与、或这轮报错停下才响。本页是文档入口。

```
用户/其他插件
     │
     ├─ 设置 → 通知 ──────────┐
     ├─ 宿主弹框内嵌选择器 ────┤
     └─ Host Service（其他插件）┘
                              │
                     目标集合解析（绑定替代默认组）
                              │
                    ┌─────────┴─────────┐
                    │  渠道适配（6 种）  │──▶ 出站 HTTP
                    └─────────┬─────────┘
                              │
                     投递结果（内存，最近 5 条/目标）

完成类通知另有前置闸门：ctx.jobs（本轮未结算的 job）+ ctx.agents（在跑的 subagent 后代）
两路都说「没活了」才推；任一路还有活 → 先不推，结算后补发
```
