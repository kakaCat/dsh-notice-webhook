层次提醒：这里是目标级过滤；配置里的三类通知开关是内容级——内容级关掉的类，目标级勾了也收不到。
交互路径：
1. 目标 A 只勾「等待授权」→ 完成事件不到 A，授权事件到 A

3. 与总开关互不影响：总开关管"默认组发不发"，本网格管"这个目标收哪几类"

交互路径：
1. 目标页只读展示"谁在用"，用于排查"这个目标被谁用"
2. **「选哪个 webhook」的界面由我们提供**：客户端服务 dshNoticeWebhookClient.renderTargetPicker(...) 返回可嵌入控件（宿主不得缓存首次返回值、不另打包 React）
3. 分工：弹框外壳归宿主；目标列表与勾选语义（默认组、凭据脱敏、空态引导）归我们；确定后宿主调 Host Service bindTargets(sessionId, ids)（空数组 = 解绑全部）
4. **会话绑定页（帧 3）**：按会话看绑了哪些 webhook，可一键解绑；绑定是**替代**默认组（不叠加）
5. 三方解绑能力：Host Service unbindTargets(sessionId)（等价 bindTargets(sid, [])），解绑后回落默认组
6. 目标被删除 → 引用它的绑定失效（视为未绑定该目标），不报错，回落默认组
