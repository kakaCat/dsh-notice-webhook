# 实施复核（REQ-260930215459-d718）

> **TL;DR**：六份设计契约逐条落地，**无偏离**；唯一需要人知情的生效条件是
> **Host 半要重启才生效**（客户端半刷新页面即可）。硬边界（出站报文 / 加签口径 / bindings / Host Service）
> 由既有断言零改动通过来证明。

## 一、契约核验

| 设计条目 | 实现 | 结论 |
|---|---|---|
| 渠道元数据表单点真相（`input`/`keyLabel`/`urlPrefix`/`keyPattern`/`secret`/`help`） | `src/channels/meta.js` | ✅ 一致 |
| `composeUrl(target)` / `parseKey(url)` 纯函数、互逆、不抛异常 | 实现在 meta.js，六个适配器给薄封装，`channels/index.js` 出统一入口 | ✅ 一致（一处实现，避免六份重复） |
| `TargetRecord` 增 `key`，`url` 变派生值 | `src/targets.js` | ✅ 一致 |
| `targets.json` v1→v2，**落盘同时保留派生 url** | `src/targets.js` | ✅ 一致（回滚前提） |
| 反解迁移：命中升级 / 不命中保留直投 | `migrateV1Record` + `composeUrlFor` 的遗留回落分支 | ✅ 一致 |
| RPC 追加式（多回 `channelMeta`/`help`/`key`，多收 `key`） | `src/rpc.js` | ✅ 一致 |
| 投递地址收敛到 `composeUrl` | `index.js`（`deliverToTarget` / `deliverTest`） | ✅ 一致 |
| 界面按原型逐元素复刻 | `client.js`（rail 三段 / content-head / card-head / 字段区 / 说明浮层 / 绑定页） | ✅ 一致（12 处差距逐条补） |

## 二、硬边界核验（不变量）

| 不变量 | 证据 |
|---|---|
| 出站报文形状与业务码判定不变 | `channels.cn`(5) + `channels.global`(4) **断言未改**即通过 |
| 钉钉/飞书加签串算法不变 | `channels.cn` 的加签断言未改 |
| 端到端报文不变 | `e2e.multi`(6) 断言未改 |
| `bindings.json` 结构不变 | `bindings.v2`(8) + `compat.v2`(8) 未改 |
| Host Service v2 签名不变 | `service.v2`(7) 未改 |
| 读容错三口径不变（空表/不覆盖/跳过坏条目） | `compat.v3` TC-15 + 既有 `compat` 用例 |

## 三、实现期修正

| # | 类别 | 内容 |
|---|---|---|
| 1 | 结构选择 | `composeUrl`/`parseKey` 的实现集中在 `meta.js`，适配器只做薄封装——设计说「各适配器加两个纯函数」，此处按「一处实现」落地以避免六份前缀逻辑分叉；对外签名与行为与设计完全一致 |
| 2 | 数据容忍 | `composeUrlFor` 增「有 key 用 key、无 key 回落原 url」分支——这是让「反解不出也不丢投递」成立的必要条件（设计 §3 的隐含要求），已在代码注释与测试中写明 |
| 3 | 如实降级 | 通用自定义渠道无官方文档，`help.docUrl` 为 `null`，界面据此**隐藏外链**（不渲染空链接） |
| 4 | 前端交互 | content-head 的两个按钮按「本页信息块开关」实现（全局参数面板 / 静态配置说明），不打开文件系统——不夸大能力 |

## 四、迁移与兼容实测

| 场景 | 实测结果 |
|---|---|
| 老 `targets.json`（只有 url） | 按前缀反解出 key 并升 v2，派生 url 与原文一致（TC-12） |
| 反解不出（手改过地址） | 保留原 url 直投 + warn，不丢目标（TC-13） |
| 混合文件 | 两种条目各按各的处理（TC-13） |
| 回滚到旧版本 | v2 里保留了派生 url，旧语义读仍能取到可投递地址（TC-14） |
| 坏文件 / 未知版本 | 空清单且不覆盖（TC-15） |

## 五、待人工确认的生效条件

| 半边 | 现状 | 要看到新行为 |
|---|---|---|
| 客户端半 | 从磁盘读，已是新版 | **刷新页面** |
| Host 半 | 运行中的进程是改动前加载的 | **重启 Host**（本轮未擅自重启） |

未重启期间，页面会优雅降级（`channelMeta` 缺失 → 回落为完整 URL 输入框，不报错）。

## 六、结论

- 设计契约逐条落地，无偏离；4 处实现期选择已如实记录；
- 硬边界守住（15 条既有断言零改动通过）；
- 迁移与回滚实测通过；
- 唯一对外提示：**Host 半需重启**才能看到「只填 key」与说明浮层的真实数据。
